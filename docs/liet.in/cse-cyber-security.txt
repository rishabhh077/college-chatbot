Syllabus
Computer Science & Engineering (Cyber Security) Labs
Cryptography and Network Security Lab
The Cryptography and Network Security Lab provides hands-on experience in securing digital systems and networks. Students learn to implement encryption algorithms, analyze network traffic, and explore tools like Wireshark, Nmap, and Metasploit. The lab focuses on real-world cybersecurity practices, including ethical hacking, secure communication protocols, and vulnerability assessment, preparing students for roles in cybersecurity and network defense.
Database Management System Lab
The Lab is dedicated for Oriented Languages and Database related practicals and projects. High configuration computer systems with relevant softwares like Java, C++, along with frontend and backend softwares like Net Beans, Visual studio, MySQL are installed to design, develop and implement Database related projects and assignments.
Web Technology Lab
The Lab is dedicated to gain hands experience on web technologies. The high configuration machines are equipped with relevant software tools like Eclipse, visual studio, PHP, Web server, XAMPP, WAMP, LAMP, and Net Beans to name a few.
